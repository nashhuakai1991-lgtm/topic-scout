# 交叉验证与防幻觉

用户要求第 3 条：「所有截取与引用的内容需与互联网信息交叉验证，
避免幻觉或主观臆断。」

分工：
- **`verify_cross.py`（脚本）**：做机械可验证的部分——多源一致性统计、
  孤证标记、指标异常、时间线异常，并输出**「必须去核的清单」**。
- **AI（写作阶段）**：拿那份清单，用 `WebSearch` 真的去互联网核校。

**两者缺一不可**：只跑脚本 = 只列了待办没做；只靠 AI 记忆 = 幻觉。

---

## 一、置信度分级（必须落到文档里）

| 置信度 | 判定标准 | 文档里的写法 |
| --- | --- | --- |
| **高** | ≥3 个独立平台一致，且数字核校通过 | 可直接作共识陈述 |
| **中** | 2 个来源支持，或数字口径有差异 | 写明来源数，提示口径差异 |
| **低** | 仅单一来源 / 来源是 UGC / 有争议 | 必须标「仅单一来源」 |

**禁止给所有结论都标高**——那样等于没有收据。

---

## 二、四路核校法（AI 在写作阶段执行）

对 `verification.json` 里 `todo_verify` 列的每一项，按需走完：

### ① 孤证核校（必做）
只有一个平台出现的说法 → 用 `WebSearch` 检索该说法 + 权威源关键词。
- 找到旁证 → 升级为中/高，记录来源
- 找不到 → **保持 low**，报告里写「仅单一来源，未检索到旁证」
- **找不到不等于不存在**，措辞用「未检索到」，不用「不存在」

### ② 数字与专名核校（必做）
一切具体数字（金额、比例、温度、时长、日期、人数）和专有名词
（人名、机构名、产品型号）都要核。

- 核到权威源后，把**自媒体说法**与**权威记载**并列写出
- 不一致时**不替作者下结论**，只呈现差异：
  「视频表述为 X，权威记载为 Y，两者口径不同」

### ③ 正反视角对照
- **正面**：主流/官方叙述
- **反面**：主动搜 `争议` `辟谣` `翻车` `错误` `不靠谱` `智商税`
- 两者都要收录并写明分歧。**反面信息往往比十条赞美更有信息量**

### ④ 时效性校验
- 主题有时效性时（价格、政策、产品版本、赛事），
  确认引用内容是否仍在有效期内
- `verify_cross.py` 已对「过旧（>3 年）」和「未来日期」打告警

## 三、脚本能自动抓的异常

`verify_cross.py` 会打出以下几类，供人工复核：

| 类型 | 含义 | 处理 |
| --- | --- | --- |
| `likes_gt_views` | 点赞 > 播放 | 指标不自洽，核该条数据 |
| `comments_gt_likes` | 评论远高于点赞 | 可能是争议内容，**必须看评论区** |
| `no_url` | 无原链接 | **不得引用**（无法溯源） |
| `no_date` | 无发布日期 | 时效性无法判断，慎引 |
| `future_date` | 日期晚于当前年 | 大概率解析错误 |
| `stale` | 发布于 3 年前 | 时效性提示 |

## 四、文档必须含的两个章节

### 章节 A：来源与可信度说明
列出所有来源 + 类型 + 可信度 + 用途。

```
| 来源 | 类型 | 可信度 | 用于 |
|---|---|---|---|
| [B站#1] xxx（官方简介） | L2 平台官方 | 中 | 主题标注、要点线索 |
| 视频转写（2 条） | L1 一手 | 高（ASR 可能有错字） | 内容总结、风格标尺 |
| 维基/官方文件 | L3 权威 | 高 | 数字与专名核校 |
| 社区讨论 | L2 社区 | 中低（有价值） | 反面视角 |
```

### 章节 B：交叉验证与存疑
- 逐条列**已核校的关键事实**：自媒体说法 → 权威记载 → 是否一致
- 逐条列**存疑点**：无法证实、来源冲突、社区争议
- 明确写「**本内容未能证实/证伪的部分**」

`make_report.py` 已自动渲染这两个板块（读 `verification.json`），
AI 需把核校结论补进正文。

## 五、话术规范

| ❌ 不要写 | ✅ 应该写 |
| --- | --- |
| 「他在视频里说过……」（其实只是简介） | 「据其官方简介……」 |
| 「这个说法是对的」（未核） | 「该说法在 N 个平台一致出现，与官方口径相符/不符」 |
| 「这是行业共识」 | 「跨 N 个平台出现，属高频说法；数字仍以权威源为准」 |
| 「没有争议」 | 「未检索到相关争议报道（检索范围有限）」 |
| 「数据表明……」（数据是孤证） | 「仅单一来源提及，尚待旁证」 |
| 直接给一个数字 | 数字 + 来源 + 口径说明 |

---

## 六、一句话原则

> **每一句话都要能回答「你凭什么这么说」。**
> 能用一手用一手；用不了就用多源；多源不一致就把差异摆出来；
> 摆不出来就标「仅单一来源」或干脆不写。
