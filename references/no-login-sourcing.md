# 不登录平台，怎么拿到内容？（实测结论）

**问题**：抖音 / 快手 / 小红书 的**搜索**都要登录。那能不能在不登录的前提下，
仍然拿到这些平台的内容？

**答案**：能，但要换思路——**不是「抓平台」，而是「借搜索引擎和公开页面的力」**。

> 本文件的每条结论均为 **2026-10-14 本机实测**，不是推测。

---

## 一、免登录可达性实测表

| 通路 | 是否免登录可用 | 能拿到什么 | 实测证据 |
| --- | --- | --- | --- |
| **各平台热榜**（`fetch_hotlist.py`） | ✅ **已自动化** | 实时榜单 + 热度值 | 抖音 50 条、微博、B站、百度均成功 |
| **搜索引擎索引**（WebSearch `site:douyin.com`） | ✅ **最有效** | **视频完整文案**、标题、作者 | 搜「site:douyin.com skill 教程」，直接返回抖音视频全文 |
| **抖音热榜接口** `aweme/v1/web/hot/search/list` | ✅ | `word_list` 50 条（含 `hot_value`） | `status_code: 0`，返回 1282 万热度条目 |
| **抖音 `/shipin/<id>` 相关视频页** | ✅ 可访问 | 视频文案（**纯文本**，无互动数） | 页面 953KB，含 100+ 条中文长句 |
| **微博热榜** `ajax/side/hotSearch` | ✅ | 实时热搜 | 返回 194 万热度条目 |
| **B站排行** `x/web-interface/ranking/v2` | ✅ | 全站排行（带播放/点赞/UP 主） | 返回 368 万播放条目 |
| **百度热榜** `top.baidu.com/api/board` | ✅ | 实时榜 | 返回 data |
| **知乎热榜** | ❌ | —— | 接口无响应（风控/需登录） |
| **快手榜单** | ❌ | —— | 走 GraphQL + 签名，免登录不可得 |
| **抖音 `/video/<id>` 单视频页** | ⚠️ 部分 | 页面可加载，`RENDER_DATA` 只有 app 配置 | 无统计数据 |
| **抖音搜索** `douyin.com/search/<kw>` | ❌ **需登录** | —— | 搜索接口 `status_code=2483`；DOM 无视频卡片 |
| **抖音话题页** `/hashtag/<id>` | ❌ **需登录** | —— | 页面 801KB 但 0 个 video id |
| **快手搜索 / `/short-video/<id>`** | ❌ **需登录** | —— | 纯 CSR（`__USE_SSR__`），HTML 无 caption/统计；接口 `result=2` |
| **小红书搜索** | ❌ **需登录** | —— | x-s/x-t 签名校验 |

> ⚠️ **重要区分**：**「热榜」免登录可得，「搜索」必须登录**。这是两码事，
> 不要因为热榜能抓就以为搜索也能。

## 二、⭐ 已自动化：各平台热榜（`fetch_hotlist.py`）

**这是本 skill 提供的免登录能力之一**，可直接跑：

```bash
# 默认抓 抖音 + 微博 + B站 + 百度
python scripts/fetch_hotlist.py --top 20 --out ./out/hot

# 抓全部（含不可用的，用于如实展示界限）
python scripts/fetch_hotlist.py --all --top 30 --out ./out/hot
```

产出 `hotlist.json` + `hotlist.md`（Markdown 表格，可直接贴报告）。

**实测可用性（2026-10-14）**：

| 平台 | 状态 | 结构 |
| --- | --- | --- |
| 抖音 | ✅ | `data.word_list[]` → `word` + `hot_value` |
| 微博 | ✅ | `data.realtime[]` → `word` + `num` |
| B站 | ✅ | `data.list[]` → `title` + `stat.view` + `owner.name` |
| 百度 | ✅ | `data.cards[0].content[]` → `word` + `hotScore` |
| 知乎 | ❌ | 接口无响应（风控/需登录） |
| 快手 | ❌ | 榜单走 GraphQL + 签名，免登录不可得 |

> ⚠️ **实现要点（踩过的坑）**：每个域名的接口**必须从该域名自己的页面上下文**里
> fetch（脚本已内置先 `goto(home)` 预热），否则会被 **CORS 拦**。
> 早先一次测试没预热，微博/知乎/B站/百度全部失败，就是这个原因。

**用途**：① 看当下什么话题在火（选题参考）；
② 判断某主题是否正上热榜（可顺势跟进）；③ 作为免登录信息源纳入报告。

## 三、⭐ 首选：搜索引擎索引（AI 用 WebSearch 执行）

**原理**：搜索引擎爬虫**不受登录限制**，已经把大量平台内容渲染并索引了。
更关键的是——**搜索结果的摘要里常常就带着视频的完整口播文案**
（平台为 SEO 会把文案渲染进页面）。

**实测例证**：搜 `site:douyin.com skill 教程`，返回结果 #2、#4 的正文片段
**就是抖音视频的完整文字内容**（"首先呢打开我们的抖平台，我们来到下方…"）。
这等于**搜索引擎替我们读完了视频并摘录了文案**。

**操作要点**：
1. 用 `site:<域名> <关键词>` 精确检索
2. 叠加平台名、话题词、`教程`/`整理`/`文字版`
3. 拿到结果后**必须标注为第三方来源**（见 `multi-source-fallback.md`），
   写成「据搜索引擎收录的该视频文案」

> ⚠️ **局限**：
> - 只能拿到**被索引过的**内容；热度数据（点赞/播放）通常拿不到
> - 时效性取决于搜索引擎的抓取频率
> - **脚本直接抓搜索引擎不可靠**（实测 Bing 从页面抓不到 `site:` 结果、
>   DuckDuckGo 超时）→ 这条路**由 AI 用 WebSearch 工具执行**，不做成脚本

## 四、次选：抖音公开页面

### 热榜 `/hot`
可直接访问，适合做「当下话题热度」类信息源。

### `/shipin/<id>` 相关视频页
- 加载后**视频文案以纯文本形式存在于 DOM**
- **但拿不到结构化互动数**（`RENDER_DATA` 里只有 app 配置）
- 适合：**补内容线索**（说它讲了什么），不适合做热度榜

> ⚠️ 用这些页面的文案时，仍是「平台公开内容」，
> 但**热度排名不可得**，报告里要说明「仅文案，无互动数据」。

## 五、其他可选路径

| 路径 | 说明 | 注意 |
| --- | --- | --- |
| **第三方数据 API**（如 TikHub 等） | 部分服务商提供抖音/快手数据接口 | 需付费、需信任第三方；**引用其数据要注明** |
| **平台官方开放平台** | 抖音/快手有面向开发者的开放接口 | 需申请资质，通常限自有账号数据 |
| **内容搬运站** | 平台内容常被搬去 B站/公众号/知乎 | 属**二手转述**，标注 🟡，不得当一手 |
| **平台 RSS/公开榜单页** | 部分榜单页免登录 | 逐案实测，勿轻信教程 |

## 六、⭐ 决策树（遇到需登录平台时）

```
目标平台需登录
   │
   ├─ 用户愿意扫码？ ──是──► 用 --profile + --headful 登录一次（数据最全）
   │                        （见 import_login.py / collect_topics.py --profile）
   │
   └─否─► 用免登录通路：
           ① fetch_hotlist.py 各平台热榜        ← 免登录、已自动化
           ② WebSearch  site:<域名> <关键词>   ← 能拿视频完整文案
           ③ 抖音 /shipin/ 页、换关键词叫法
   │
   └─► 交付时：分层标注（平台条目 vs 第三方来源），写清哪些未纳入、为什么
```

## 七、与「持久化 profile」的关系

**这是拿全量数据的最佳方式**（数据最全、可复用）：

```bash
# 1) 开可见窗口，用户扫一次码（登录态落盘到 ./profile）
python collect_topics.py --topic "…" --platform douyin --profile ./profile --headful

# 2) 之后同 profile 直接抓，不用再扫
python collect_topics.py --topic "…" --platform douyin --profile ./profile
```

或复用**本机浏览器已登录的 cookie**：

```bash
python import_login.py --browser chrome --domain douyin.com --out ./cookies
python collect_topics.py --topic "…" --platform douyin --cookies ./cookies/douyin.com.json
```

> ⚠️ **Chrome 正在运行时其 cookie 库被独占锁定**，`import_login.py` 会明确提示
> 「请先完全退出浏览器」。这是已知限制，不是脚本缺陷。
> 不想关浏览器 → 用 `--profile` 扫码方式。

---

## 八、一句话总结

> **登录是为了「搜索」；不登录也可以用「搜索引擎 + 公开页」拿到内容线索。
> 要全量、要互动数据，才需要登录。** 三条路按需选，但**无论走哪条，
> 都必须如实标注来源层级**。
